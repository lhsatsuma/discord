# Superadministrator Commands

This page lists commands reserved for the bot operator. They are restricted to the channel configured by `DISCORD_BOT_ADMIN_CHANNEL`.

| Command | Description |
|---|---|
| `/superadmin status` | Displays app and scheduler status. |
| `/superadmin logs` | Posts recent process log lines to the operator channel. |

For installation and technical documentation, see [Installation and Configuration](Superadministrator-Installation), [Architecture](Superadministrator-Architecture), and [Adding Commands](Superadministrator-Adding-Commands).
