# Adding commands

Commands are discovered automatically from `src/controllers/commands/`. Follow the folder and class conventions so the loader can import and dispatch the command.

## Add a simple slash command

Create a directory and a file with the same name:

```text
src/controllers/commands/hello/hello.ts
```

Use the base command class, build the slash command, and implement its handler:

```ts
import { ChatInputCommandInteraction, SlashCommandBuilder } from 'discord.js';
import lang from '#includes/lang.ts';
import appCommandInterface from '#interfaces/appCommandInterface.ts';

export default class hello extends appCommandInterface
{
    name = 'hello';

    async build()
    {
        this.builded = new SlashCommandBuilder()
            .setName(lang.translate(this.name, 'CMD_HELLO_NAME'))
            .setDescription(lang.translate(this.name, 'CMD_HELLO_DESCRIPTION'));

        return super.build();
    }

    async execute(interaction: ChatInputCommandInteraction)
    {
        await interaction.reply(lang.translate(this.name, 'CMD_HELLO_SUCCESS'));
        return true;
    }
}
```

The default export must be a class: the loader constructs it with the bot instance, calls `init()`, then calls `build()`. The class name, its `name` value, and the directory/file name should all match.

## Add a command with subcommands

Create a root command and set `hasSubcommands` to `true`:

```text
src/controllers/commands/greetings/greetings.ts
src/controllers/commands/greetings/subs/hello.ts
```

Root command:

```ts
import { SlashCommandBuilder } from 'discord.js';
import lang from '#includes/lang.ts';
import appCommandInterface from '#interfaces/appCommandInterface.ts';

export default class greetings extends appCommandInterface
{
    name = 'greetings';
    hasSubcommands = true;

    async build()
    {
        this.builded = new SlashCommandBuilder()
            .setName(lang.translate(this.name, 'CMD_GREETINGS_NAME'))
            .setDescription(lang.translate(this.name, 'CMD_GREETINGS_DESCRIPTION'));

        return super.build();
    }
}
```

Subcommand:

```ts
import { ChatInputCommandInteraction, SlashCommandSubcommandBuilder } from 'discord.js';
import lang from '#includes/lang.ts';
import appSubCommandInterface from '#interfaces/appSubCommandInterface.ts';

export default class greetings_hello extends appSubCommandInterface
{
    parentName = 'greetings';
    name = 'hello';

    build()
    {
        this.builded = new SlashCommandSubcommandBuilder()
            .setName(lang.translate(this.parentName, 'SUBCMD_HELLO_NAME'))
            .setDescription(lang.translate(this.parentName, 'SUBCMD_HELLO_DESCRIPTION'));

        return this;
    }

    async execute(interaction: ChatInputCommandInteraction)
    {
        await interaction.reply(lang.translate(this.parentName, 'SUBCMD_HELLO_SUCCESS'));
        return true;
    }
}
```

The subcommand file name is used during loading; the class's `parentName` must match the root command's `name`. Add any Discord options to the builder and read them from `interaction.options` in `execute()`.

## Add translations

Create a JSON file named after the command's internal name in each locale directory used by the bot. For example, `src/locales/pt-BR/greetings.json`:

```json
{
  "CMD_GREETINGS_NAME": "saudacoes",
  "CMD_GREETINGS_DESCRIPTION": "Comandos de saudação",
  "SUBCMD_HELLO_NAME": "ola",
  "SUBCMD_HELLO_DESCRIPTION": "Responde com uma saudação",
  "SUBCMD_HELLO_SUCCESS": "Olá!"
}
```

For a simple command, use the `CMD_HELLO_*` keys shown in its example. For a command with subcommands, root keys use `CMD_<COMMAND>_*` and subcommand keys use `SUBCMD_<SUBCOMMAND>_*`. Keep slash-command names valid according to Discord's naming rules and consistent across the configured locales.

## Register and verify

1. Run `npm run build` to type-check the project.
2. To have startup publish command definitions to Discord, set `DISCORD_BOT_SEND_COMMANDS_API=true` in `.env` and start the bot. When it is false, register updated definitions through your normal deployment process.
3. Restart the bot and check startup logs for command-loading errors.
4. Test the command in a Discord server where the bot is installed.

## Optional: use a modal

For modal-based input, put the modal implementation under `src/controllers/modals/<command>/`. Extend `appModalInterface`, set `parentName` and `name`, and implement `buildComponents()` and `execute()`. A subcommand can construct the modal with `new YourModal(this.main).init()` and pass `modal.builded` to `interaction.showModal()`. The custom ID is generated by the base modal class.
